# GitHub Pages site (build artifact)

**Canonical source:** `marimo_notebooks/` (+ `helpers.py`, `spectral_methods.py`).

Do not edit WASM chapter contents by hand. Rebuild:

```bash
python marimo_exports/export_wasm.py --sync-docs --verify
# static FastAPI mirror only:
python marimo_exports/static_api.py
```

| Path | Role |
|------|------|
| `index.html` | Book gallery (checked in) |
| `wasm/*/` | Generated by export from notebooks |
| `api/` | **Static FastAPI mirror** (JSON + Swagger explorer) |
| `api/health.json` | Health + bundle summary |
| `api/features/*.json` | Spectral / subject / condition tables |
| `api/openapi.json` | OpenAPI 3 schema for the static API |
| `.nojekyll` | Required for Pages asset serving |

## Public API (GitHub Pages)

GitHub Pages cannot run `uvicorn`. The local FastAPI app
(`marimo_exports/fastapi_app.py`) is frozen into static files under `api/`:

- Explorer: `/api/`
- Example: `/api/health.json`, `/api/features/spectral_clean.json`

Local live routes (no `.json` suffix): `python marimo_exports/serve.py --fastapi`

CI (`.github/workflows/deploy-pages.yml`) runs the WASM export + static API
export and deploys all of `docs/`.
