# Repo architecture — Music, Reward & Depression (ds000171)

Focused, reproducible pipeline on OpenNeuro **[ds000171](https://openneuro.org/datasets/ds000171)**
(*Neural Processing of Emotional Musical and Nonmusical Stimuli in Depression*).
BOLD fMRI (TR = 3 s), block design (~30 s): positive/negative **music** vs **nonmusic**
and **tones**, cohorts **MDD** and never-depressed **Control**.

Goal: spectral biomarkers of music-reward / anhedonia → classical ML bake-off vs
TensorFlow spectrogram models → packaged as an interactive **methods book**.

## Data & features

| Artifact | Role |
|----------|------|
| `spectral_features.csv` | Run-level PSD bands + QC (+ `psd_f`/`psd_pxx` in bundle) |
| `cleaned_spectral_features.csv` | IsolationForest-gated runs |
| `condition_features.csv` | Trial-type epochs (pos/neg music, nonmusic, tones) |
| `subject_features.csv` | Wide table + **responder score R** + music contrasts |
| `run_qc.csv` | tSNR / flatness / spike / IF flags |
| `ml_bakeoff.json` | LOOCV leaderboards + winners |
| `tf_results.json` | Offline neural metrics for Ch V |

**PSD methods** (`prepare_real_features.py --psd`):

- `welch` — legacy Hann baseline  
- `uniform` — equal-weight DPSS multitaper  
- `adaptive` — **default** Thomson-style weights (scipy; WASM-safe)  
- `mne` — optional production adaptive multitaper

## Cross-reference OpenNeuro datasets

Use these for spectral / music-reward validation (all BIDS, public):

| ID | Focus | Why cross-ref |
|----|--------|----------------|
| [ds002725](https://openneuro.org/datasets/ds002725) | Joint EEG–fMRI affective music | Multimodal spectral / ERP vs BOLD PSD |
| [ds003085](https://openneuro.org/datasets/ds003085) | Temporal dynamics of emotional music | Happy/sad music blocks |
| [ds003720](https://openneuro.org/datasets/ds003720) | Music genre fMRI | Genre-specific auditory structure |
| [ds004142](https://openneuro.org/datasets/ds004142) | rt-fMRI neurofeedback reward valence | Reward / saliency |
| [ds005700](https://openneuro.org/datasets/ds005700) | NeuroEmo (Bollywood clips) | Emotion labels incl. depressed |
| [ds006564](https://openneuro.org/datasets/ds006564) | Film + musical soundtracks | Depression/anxiety traits + music |

Pipeline reuse: place a BIDS tree under `data/raw/<id>/` and adapt
`prepare_real_features.py` paths / TR if needed.

## Typical workflow

```bash
pyenv shell 3.12.13   # or any ≥3.11
pip install -r requirements.txt

# Features (local NIfTI)
python scripts/prepare_real_features.py --psd adaptive
python scripts/run_ml_bakeoff.py
# optional: python scripts/run_tf_offline.py

# Live book + REST
export PYTHONPATH=marimo_notebooks
uvicorn app:app --reload --port 8000
# open http://127.0.0.1:8000/book/00_qc_dashboard/
#      http://127.0.0.1:8000/api/docs  (OpenAPI)
#      http://127.0.0.1:8000/api/architecture

# Publish static book + API mirror
python marimo_exports/export_wasm.py --sync-docs --verify
# push main → GitHub Actions → Pages
```

## Scaling notes — God-mode Spark (honour)

**Rule:** CUDA/FFT **outside** the JVM; Spark is pure Tungsten/Catalyst; GPU only in `tf.data` / TF training.

```bash
# 1) Download cross-ref metadata (+ optional BOLD)
python scripts/download_openneuro_cohorts.py
python scripts/download_openneuro_cohorts.py --with-bold --max-subjects 1 --only ds002725

# 2) Pre-ingest NIfTI → Parquet (scipy multitaper; optional --backend cupy)
python scripts/pre_ingest_bold_to_parquet.py --datasets ds000171,ds002725

# 3) Catalyst scale-out + TFRecords hand-off
python scripts/god_mode_bold_to_tfdata.py --smoke-tfdata
# optional Connect:
# docker compose -f docker-compose.spark.yml up -d
# python scripts/god_mode_bold_to_tfdata.py --remote sc://localhost:15002

# 4) Explore
export PYTHONPATH=marimo_notebooks
marimo edit marimo_notebooks/07_spark_god_mode.py
```

| Path | Role |
|------|------|
| `data/processed/dataset_registry.json` | Multi-dataset inventory |
| `data/processed/god_parquet_bold/` | Epoch TS arrays + run spectral (pre-Spark) |
| `data/processed/god_features/` | Catalyst subject/run tables |
| `data/processed/god_tfrecords/` | Sacred TF hand-off |
| `docker-compose.spark.yml` | Classic Spark Connect (CPU) + optional Kafka profile |
| `scripts/spark_streaming_bold.py` | Structured Streaming (file/Kafka, checkpoint, dynamic SQL) |
| `stream_inbox/` · `stream_features/` · `stream_checkpoints/` | Streaming I/O + recovery |

Public WASM book still uses the smaller `spectral_features.csv` store. God-mode is the **horizontal** path for multi-dataset / larger *n*.
